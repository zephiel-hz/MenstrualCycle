# Ricil's - Your Personal Cycle Companion 🌙

**Ricil's** adalah aplikasi **Progressive Web App (PWA) untuk pelacakan siklus menstruasi** modern, mobile-first, dan privacy-first. Dibangun menggunakan satu codebase untuk seluruh platform (Android, iOS/iPadOS, Windows, macOS, Linux, dan modern web browser) dengan backend 100% serverless yang siap dideploy di Vercel dan terhubung ke Neon PostgreSQL melalui Drizzle ORM.
